# vanpallethout-website
Repository containing the code for a django-port of https://www.vanpallethout.nl

## Background
Years back, I built a rudimentary website for my dad's furniture company _Van Pallethout_. This website is outdated and is only maintainable by me. My goals is to rebuilt the website on Django, and to provide my dad with a way to upload his own pictures without needing to contact me.
